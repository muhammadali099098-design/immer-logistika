# IMMER Logistika (Render)

Система учёта грузов на складе логиста **по моделям техники**.
Публичный доступ — логисты входят по логину, который создаёт администратор (вы).

## Что делает
- **Склад по моделям** — вы видите остаток своего товара на складе каждого логиста.
  Для каждой модели: остаток, с какого завода загружен, и стоимость логистики.
- **Приход** — логист загрузил груз с завода и привёз на свой склад (модели + количество).
- **Отгрузка в Узбекистан** — со склада уходит фура с товаром. Можно смешивать
  модели из разных партий (30% от одной, 70% от другой). **За каждую фуру вы платите
  логисту** — стоимость записывается в отгрузке.
- Остаток по модели = пришло с заводов − отгружено в Узбекистан.

## Роли
- **Администратор (вы)** — видит склад всех логистов, ведёт справочники (модели, заводы, логисты) и пользователей.
- **Логист** — видит и ведёт только склад своей компании (приходы и отгрузки).

## Стек и развёртывание
- Node.js + Express (без нативных модулей)
- Данные в Google Sheets (служебный аккаунт), как в «Реестре заводов»
- Сессии на подписанных cookie, пароли хэшируются (PBKDF2)

### Шаг 1. Google-таблица
- Создайте пустую таблицу в Google Sheets.
- «Поделиться» → добавьте **email служебного аккаунта** с правом **Редактор**.
- Скопируйте **ID таблицы** из адреса: `docs.google.com/spreadsheets/d/<ID>/edit`

### Шаг 2. Код на GitHub
- Распакуйте архив, создайте репозиторий (например `immer-logistika`) и загрузите файлы проекта.

### Шаг 3. Render
- New → Web Service → подключите репозиторий.
- Build: `npm install` · Start: `npm start` · Node 20+
- Переменные окружения:
  - `AUTH_SECRET` — любой длинный секретный текст
  - `GOOGLE_SERVICE_ACCOUNT` — содержимое JSON-ключа служебного аккаунта
  - `GOOGLE_SHEET_ID` — ID таблицы
- Deploy. При первом запуске система создаст нужные вкладки в таблице.

### Первый вход
Откройте сайт → «Первый вход? Создать администратора» → логин, имя, пароль.
Дальше: добавьте модели, заводы, логистов → создайте аккаунты логистов → записывайте приходы и отгрузки.
