# IMMER Logistika (Render)

Система учёта грузов на складах логистов **по моделям техники**, по вашей схеме работы.

## Как работает
- **Заводы** — справочник (Hangdi, Jidea, и т.д.), откуда грузится товар.
- **Модели** — справочник товара с **объёмом (CBM за 1 шт)**, как в вашем файле.
- **Загрузка (PI)** — партия с завода, разбитая на **фуры**. Каждая фура: номер, дата, модели + количество.
- **Отгрузка в Узбекистан** — фура со склада; за каждую фуру фиксируется **стоимость логистики**.
- **Оплата** — платёж по номеру документа; чтобы провести оплату, нужны загруженный документ и заполненное поле **«0.4%»** у фуры (кнопка «✎» → поле «0.4%»). Без 0.4% оплата не проводится.
- **Приёмка** — отмечается документом о получении; при повторном открытии показывает сохранённые данные (дата, штрафы, документ) и позволяет их менять.
- **Документы партии** — кнопка-иконка в таблице «Граница → Ташкент» открывает все загруженные файлы по партии (приём, отметка об оплате, платёжные документы). Файлы можно удалять прямо из этого окна: удаление платёжного документа удаляет сам платёж и пересчитывает долг. При удалении отгрузки её платежи удаляются вместе с ней.
- **Выбор товаров при отгрузке** — в окне «Выбрать товары» видны сразу все заказы: можно отметить товары из разных Order № и добавить всё одним нажатием.
- **Склад по моделям** — остаток = загружено с заводов − отгружено, с количеством и объёмом (CBM).

## Роли
- **Администратор (вы)** — видит всё, ведёт справочники и аккаунты логистов.
- **Логист** — видит и ведёт **только свою** загрузку и отгрузку (у каждого свой склад).

## Стек и развёртывание
- Node.js + Express (без нативных модулей)
- Данные в Google Sheets (служебный аккаунт), как в «Реестре заводов»
- Сессии на подписанных cookie, пароли хэшируются (PBKDF2)
- Встроенный кэш (защита от лимита Google), запрет кэша в браузере

### Шаг 1. Google-таблица
Создайте пустую таблицу → «Поделиться» с email служебного аккаунта (Редактор) → скопируйте ID из адреса.

### Шаг 2. Код на GitHub
Распакуйте архив, загрузите файлы проекта в репозиторий.

### Шаг 3. Render
Web Service → Build: `npm install` · Start: `npm start` · Node 20+.
Переменные: `AUTH_SECRET`, `GOOGLE_SERVICE_ACCOUNT`, `GOOGLE_SHEET_ID`.
Deploy. При первом запуске создаст вкладки в таблице.

### Первый вход
«Первый вход? Создать администратора» → логин, имя, пароль.
Дальше: добавьте модели (с CBM), заводы, логистов → создайте аккаунты логистов → заводите PI-загрузки с фурами и отгрузки.

### Чтобы сайт не «засыпал»
Настройте пинг на cron-job.org (URL сайта, каждые 10 минут) — иначе бесплатный Render «спит» после ~15 минут без действий.
