# Исправления QA — 2026-08-19

Исправлены 11 пунктов из топ-10 приоритетов аудита (`QA-audit-...md`).

## ⚠️ ОБЯЗАТЕЛЬНО перед деплоем
Задайте переменную окружения **`AUTH_SECRET`** (Render → Settings → Environment → Add
Environment Variable). Иначе приложение НЕ запустится (это сделано специально — раньше
использовался известный секрет по умолчанию, и сессию можно было подделать).
После установки все текущие сессии сбросятся — нужно будет войти заново. Это нормально.

## Что изменено

- **BUG-001 (критично).** Кнопка «Загрузить пример» больше НЕ стирает базу. Эндпоинт
  `/api/seed` теперь работает только на полностью пустой базе, иначе отменяется. Убраны все
  `store.clear()`. Кнопка переименована + запрашивает подтверждение.
- **BUG-002.** ID больше не переиспользуются. При удалении строки её `id` сохраняется
  («надгробие»), а `nextId` считает максимум по сырой колонке A — новый id всегда больше.
- **BUG-003.** Нельзя удалить модель / завод / логиста, если они используются в
  загрузках/отгрузках/Ташкенте/пользователях — сервер вернёт понятную ошибку с числом ссылок.
- **BUG-004.** На телефоне боковое меню открывается по кнопке ☰ (выезжающая панель + затемнение,
  закрывается по тапу вне меню или по пункту). Раньше меню было полностью недоступно на мобиле.
- **BUG-005.** Двойной клик / повторная отправка больше не создаёт дубликаты: одинаковые
  одновременные запросы схлопываются в один, записи (POST/PUT/DELETE) не повторяются при обрыве
  сети, а кнопки-действия защищены от быстрого двойного нажатия.
- **BUG-006.** Требуется стойкий `AUTH_SECRET` в проде (см. выше), cookie помечается `Secure`.
- **BUG-007.** Серверные ограничения на количество/суммы; ущерб не может превышать стоимость фуры.
- **BUG-008.** Тост больше не перерисовывает весь экран; в таблице «Граница → Ташкент» добавлена
  постраничная навигация (по 50 строк).
- **BUG-009.** Ограничение попыток входа (10 за 15 минут на IP+логин).
- **BUG-010.** Ошибка входа больше не раскрывает внутренние детали сервера.
- **BUG-012.** Название модели экранируется (закрыт stored-XSS).
- **BUG-017.** Добавлены базовые заголовки безопасности (CSP, X-Frame-Options и т.д.).

## Что НЕ вошло (осознанно, на будущее)
- Серверная идемпотентность по ключу (сейчас достаточно схлопывания одинаковых запросов).
- Загруженные файлы всё ещё пропадают при перезапуске Render (нужно внешнее хранилище, напр. S3).
- Инвалидация старых сессий при смене пароля (token_version).

## Заметка
Записи-«надгробия» (удалённые строки) остаются в таблице с одним только `id` в колонке A —
это нормально и нужно для того, чтобы id не переиспользовались. В отчётах и списках они не видны.
